# OmniBrain-0 website

The website source and static resources are maintained on the `page` branch.
The `main` branch contains the research project README and Python utilities.

Live site: https://luo-yc17.github.io/OmniBrain-0/
Public-BOTs site: https://public-bots.github.io/OmniBrain-0/

## Preview

On the `page` branch, run `python3 -m http.server 8000` from the repository root
and open http://localhost:8000/.

## Publish

GitHub Pages publishes from the root of the `page` branch using
Settings > Pages > Deploy from a branch > page > /(root).
Push website changes to `page`; no website files are required on `main`.
